# Client icon sources

Stop Stutter uses client icons to identify the apps it can work with. The client names and artwork belong to their respective owners; inclusion does not imply affiliation or endorsement. Stop Stutter's MIT license applies to its original code and artwork, and does not relicense these third-party assets.

When a client is installed, Stop Stutter uses its local application icon. The bundled copies below provide the same recognizable identity before installation. No icon downloads occur at runtime.

| File | Source |
| --- | --- |
| `com.moonlight-stream.Moonlight.icns` | [Moonlight's official source tree](https://github.com/moonlight-stream/moonlight-qt/blob/master/app/moonlight.icns); Moonlight is distributed under GPLv3, reproduced in `MOONLIGHT-LICENSE.txt`. |
| `com.nvidia.gfnpc.mall.icns` | `cefsimple.icns` from NVIDIA's [official GeForce NOW macOS distribution](https://download.nvidia.com/gfnpc/GeForceNOW-release.dmg). NVIDIA artwork. |
| `io.unom.punktfunk.icns` | `punktfunk_Logo.icns` from the installed Punktfunk macOS client, bundle ID `io.unom.punktfunk`. [Punktfunk project](https://git.unom.io/unom/punktfunk). |
| `tv.parsec.www.icns` | `Parsec.icns` from the [official Parsec macOS package](https://builds.parsec.app/package/parsec-macos.pkg). Parsec artwork. |
| `com.valvesoftware.SteamLink17.jpg` | Artwork supplied by Valve through the [Steam Link App Store listing](https://apps.apple.com/us/app/steam-link/id1246969117?platform=mac). Valve artwork. |
